    Claim this hub

    Switching rows and sending commands to the bays is for the hub's admin. Claiming the hub gives this browser its admin key, after a press on the hub's BOOT button: nobody can claim it from the network alone.

    Press the hub's BOOT button once, briefly: its CTL LED flickers.

    1:00

    Or type hub access claim on its console USB-C.

    Claimed. This browser keeps the admin key. Keep a copy: the bays can use the same one.

    Unlock as admin

    Paste the hub's admin key (from when you claimed it, or the rack's key if it was claimed with that one). It stays in this browser; requests are signed with it, the key itself is not sent.

    Lost it? hub access reset on the hub's console USB-C, or hold its BOOT button for 10 s.
