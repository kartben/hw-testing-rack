    Claim this bay

    This node has no admin yet. Claiming it gives this browser its admin key, after a press on the node's BOOT button: nobody can claim a bay from the network alone.

    Press the BOOT button of this bay once, briefly: its LED is blinking white.

    1:00

    Or type bay access claim on its local console.

    Claimed. This browser keeps the admin key. Keep a copy: bayctl (BAYCTL_KEY) and the other bays can use the same one.

    Unlock as admin

    Paste this bay's admin key (from bayctl access keygen, another bay, or when you claimed it). It stays in this browser; requests are signed with it, the key itself is not sent.

    Lost it? On the node: bay access reset, or hold BOOT for 10 s.

    Reserve this bay

    While reserved, power, reset, the console and USB/IP answer only your address (and it ends by itself). CI does this with bayctl lease.
